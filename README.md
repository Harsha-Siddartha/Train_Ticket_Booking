# Train Ticket Booking System

## Project Description

The Train Ticket Booking System is a C-based application developed using
file handling and modular programming. It allows users to manage train
information, passenger details, ticket reservations, cancellations,
and user authentication.

## Features

- User Sign Up and Sign In
- Admin Login
- View Train Information
- Book Train Tickets
- Cancel Train Tickets
- Manage Passenger Information
- File-based Data Storage
- Makefile for easy compilation

## Technologies Used

- C Programming
- File Handling
- Structures
- Functions
- Makefile
- Linux
